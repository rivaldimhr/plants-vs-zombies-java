Plants vs Zombies (Java)

Kode Unduh JAR

Game ini dimainkan dengan mouse dan butuh layar lebar. Di ponsel, buka halaman ini dari laptop, atau lihat cuplikan gameplay di README.

Game Java asli, berjalan di browser

Kode Java Swing yang sama dengan versi desktop, dijalankan oleh mesin Java di dalam browser. Pemuatan pertama sekitar 20–60 detik; berikutnya lebih cepat.

Cara bermain

  • Klik START, pilih level, lalu pilih 6 tanaman untuk deck.
  • Klik kartu tanaman lalu klik petak halaman untuk menanam. Klik sun yang jatuh untuk mengumpulkannya.
  • Klik kanan untuk batal memilih. Keyboard: panah + Enter pilih petak, 1–6 tanam, 7 cabut, P / Esc jeda, F kecepatan 2×.
  • Progres level tersimpan di browser ini.

Tentang versi browser

Ini file .jar yang sama dengan rilis desktop, dijalankan oleh CheerpJ (JVM dalam WebAssembly). Tidak ada kode yang ditulis ulang. Jika terasa patah-patah, unduh JAR dan jalankan dengan Java 17+.

Proyek belajar non-komersial. Aset gambar Plants vs. Zombies milik PopCap Games / Electronic Arts; kode berlisensi MIT, suara dan musik dibuat sendiri.
